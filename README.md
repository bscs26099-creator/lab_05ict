TECH HUB is a simple e-commerce website designed to provide users with different technology and gaming products. The website has three main pages: Home, Products, and About Us.

The Home page introduces the TECH HUB brand and displays a main image along with a button that takes users to the products page. The Products page shows different products such as a Gaming CPU, Gaming Keyboard, Gaming Mouse, Gaming Headphones, and LED TV. Each product includes an image, price, description, and a button to check its availability.

The About Us page provides contact information, including the phone number, email address, and location of TECH HUB. It also includes social media links. The website uses HTML for its structure, CSS for styling, and JavaScript for interactive features, such as welcome messages and checking product availability.
